## 評審追問 Q&A

| 問 | 答 |
|---|---|
| 分數是違法認定嗎？ | 不是。分數只是查核排序工具；畫面每頁都寫「不是違法認定」，行政判斷由權責機關依正式事證作成。 |
| 資料是真的嗎？ | 園所、評鑑結果來自教育部全國教保資訊網（真）；財務與收費依競賽規範用合成資料，正式版走教育局內部授權資料，不出局。 |
| 座標準嗎？ | 現階段為園所所在區域定位，正式版用 TGOS 門牌定位批次轉換。 |
| AI 幻覺怎麼辦？ | AI 只產生「要查什麼」的清單，不產生結論；分數來自規則引擎；承辦人逐項確認。 |
| 跟 Excel 差在哪？ | 來源可追溯、規則可版本化、案件可留痕、跨承辦人可交接。 |
| 示範分數超過 100？ | 裁罰按次累加，累計風險點數可超過 100，是刻意設計；等級門檻可調。（若被追問，主動說明，不要迴避。） |
| 部署在哪？ | AWS us-west-2 單台 EC2 + RDS，GitHub Actions `deploy_*` tag 自動部署，主辦帳號內。 |

## 操作提醒

- 地圖沒網路時底圖會空白但標記照常；現場先確認 Wi-Fi。
- 登入後若不在總覽，點側欄「風險總覽」。
- 切回真實園所：篩選列的「真實園所 110 間」按鈕。
- 不要點「重設為初始示範資料」（會清覆核紀錄）。
